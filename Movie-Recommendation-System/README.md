# 🎬 Movie Recommendation System

## 📌 Project Overview

A content-based Movie Recommendation System built using Python, Scikit-learn, and Streamlit.

This project recommends similar movies based on movie features such as genres, keywords, cast, director, and overview.

## 🎯 Objectives

* Recommend similar movies based on content.
* Build an interactive Streamlit application.
* Display movie posters and details using TMDB API.

## 🛠️ Technologies Used

* Python
* Pandas
* Scikit-learn
* CountVectorizer
* Cosine Similarity
* Streamlit
* TMDB API

## ⚙️ How It Works

1. Load and preprocess movie data.
2. Combine movie features into tags.
3. Convert tags into numerical vectors using CountVectorizer.
4. Calculate similarity using cosine similarity.
5. Recommend similar movies.

## ✨ Features

* Movie search
* Similar movie recommendations
* Movie posters and details
* Interactive Streamlit UI
* TMDB API integration
